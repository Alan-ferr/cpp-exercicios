# Exercícios de Programação Competitiva em C++

Repositório com exercícios resolvidos em C++, desenvolvidos durante disciplinas
de algoritmos/programação (UFABC) e problemas de programação competitiva
(OBI). Cobre lógica, matemática (teoria dos números, primos, MDC/MMC),
manipulação de vetores e strings.

## Estrutura

```
cpp-exercicios/
├── lista2/    # Geometria básica (triângulos, distância entre pontos, polígonos)
├── lista3/    # Trapézios, fatores próprios, números perfeitos, primos em intervalo
├── lista4/    # Soma de primos por dígito final
├── lista5/    # MDC/MMC, maior divisor primo, twin primes, fórmula de Euler
├── lista6/    # Fibonacci, k-primos gêmeos, Conjectura de Goldbach, vetores
├── provas/    # Exercícios avaliativos feitos em classe
└── obi2008/   # Problemas da OBI 2008 (nível júnior)
```

## Tecnologias

- C++ (padrão C++11+)
- Compilado e testado no OnlineGDB

## Observação

Alguns arquivos foram reconstruídos a partir de fotos de tela e podem conter
pequenas diferenças em relação à submissão original — a lógica foi mantida
fiel ao enunciado de cada problema.
